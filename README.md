# 치지직 방송 관리 매니저 (CHZZK Manager)

인터넷 방송 스트리머가 **방송 기록, 후원(치즈), 시청자**를 관리하고 **월별·카테고리별 통계**를 볼 수 있는 Java 콘솔 프로그램입니다.

> 문제해결및실습: JAVA (009956-004) 2026-2 개인 프로젝트

---

## 1. 문제 정의와 목표

**문제:** 개인 스트리머는 방송이 끝나면 "오늘 몇 명이 봤는지, 누가 얼마를 후원했는지, 미션 후원은 성공했는지"를 메모장이나 엑셀에 따로 적어 둡니다. 기록이 흩어져 있으면 다음 같은 질문에 답하기 어렵습니다.

- 이번 달에 방송을 몇 시간 했고, 후원은 얼마나 정산되었나?
- 어떤 카테고리(게임)를 할 때 시청자가 가장 많았나?
- 가장 많이 후원해 준 시청자는 누구인가?
- 진행중인 미션 후원이 몇 건 남았나?

**목표:** 방송, 후원, 시청자 데이터를 한 프로그램에서 등록·조회·수정·삭제하고, 파일에 저장해 두었다가 다시 불러와 통계를 계산하는 도구를 만듭니다.

## 2. 주요 기능

| # | 기능 | 세부 내용 |
|---|------|-----------|
| 1 | **방송 기록 관리** | 방송 등록 / 목록(최신순·오래된순·시청자순·방송시간순 정렬) / 검색(제목 키워드, 카테고리) / 상세 보기(해당 방송 후원 내역 포함) / 수정 / 삭제(연결된 후원도 함께 삭제) |
| 2 | **후원(치즈) 관리** | 일반·영상·미션 후원 등록 / 전체 및 방송별 조회 / 미션 결과 처리(성공·실패) / 삭제. 블랙리스트 시청자의 후원은 거부 |
| 3 | **시청자 관리** | 시청자 목록 / 닉네임 부분 검색과 상세(누적 후원) / 등록 / 메모 수정 / 블랙리스트 추가·해제 / 삭제(후원 기록이 없을 때만) |
| 4 | **통계 / 분석** | 월별 요약(방송 횟수, 총 방송 시간, 평균 최고 시청자, 후원 합계) / 카테고리별 평균 시청자·방송 횟수·방송 시간 / 후원자 랭킹 TOP 10 / 후원 많이 받은 방송 TOP 5 / 후원 종류별 합계 |
| - | **파일 저장·불러오기** | 시작할 때 `data/*.csv`를 자동으로 불러오고, 데이터를 바꿀 때마다 자동 저장. 종료할 때도 저장 |

**정산 규칙:** 일반·영상 후원은 금액 전체가 정산됩니다. 미션 후원은 **성공했을 때만** 정산되고, 진행중이거나 실패(환불)면 정산 금액이 0입니다. 통계와 랭킹은 정산 금액을 기준으로 합니다.

## 4. 실행 방법

> 모든 명령은 **프로젝트 최상위 폴더**(이 README가 있는 폴더)에서 실행합니다.
> 프로그램은 실행 위치 기준 `data/` 폴더를 사용합니다.

### 방법 A. 스크립트로 실행 (가장 간단)

- **Windows:** `run.bat` 더블클릭, 또는 명령 프롬프트에서 `run.bat`
- **macOS / Linux:**
  ```
  chmod +x run.sh
  ./run.sh
  ```

### 방법 B. 명령어로 직접 컴파일·실행 (Windows / macOS / Linux 공통)

```
javac -encoding UTF-8 -d out -sourcepath src src/app/Main.java
java -cp out app.Main
```

- `-sourcepath src`를 지정하면 `Main.java`가 사용하는 나머지 클래스가 모두 자동으로 컴파일됩니다.
- 다른 데이터 폴더를 쓰고 싶으면 경로를 인자로 넘깁니다. 예: `java -cp out app.Main mydata`

### 방법 C. IDE (IntelliJ IDEA / Eclipse)

1. 프로젝트 폴더를 엽니다.
2. `src` 폴더를 소스 루트로 지정합니다. (IntelliJ: `src` 우클릭 → Mark Directory as → Sources Root)
3. `src/app/Main.java`를 실행합니다.
4. 실행 설정의 **Working directory가 프로젝트 최상위 폴더**인지 확인합니다. (그래야 `data/`를 찾습니다)

### 샘플 데이터 되돌리기

테스트하면서 데이터를 바꾼 뒤 처음 상태로 되돌리려면:
```
git checkout -- data
```

## 5. 사용 방법 (메뉴별 안내)

### 5-0. 기본 조작

- 화면에 나온 **번호를 입력하고 Enter**를 누릅니다.
- 메뉴에서 **`0`을 누르면 뒤로** 갑니다. 메인 메뉴에서 `0`을 누르면 저장하고 종료합니다.
- 질문이 나오면 값을 입력하고 Enter를 누릅니다. 잘못 입력하면 안내 메시지가 나오고 **같은 질문을 다시** 합니다.
- 데이터를 추가·수정·삭제하면 **자동으로 저장**됩니다. 따로 저장하지 않아도 됩니다.
- 방송이나 후원을 고를 때는 목록 맨 앞의 **`[ 9]` 같은 숫자(ID)**를 입력합니다.

**입력을 편하게 해 주는 기능**

| 상황 | 방법 |
|------|------|
| 날짜를 오늘로 | 날짜 질문에서 그냥 **Enter** |
| 후원 시각을 지금으로 | 시각 질문에서 그냥 **Enter** |
| 수정할 때 기존 값 유지 | 해당 질문에서 그냥 **Enter** |
| 금액 입력 | `10000`, `10,000` 둘 다 됨 |
| 카테고리, 후원 종류 | 목록에서 **번호**로 선택 |

### 5-2. `1` 방송 기록 관리

```
[방송 기록 관리]

  2. 방송 목록 (정렬)

  5. 방송 수정
  6. 방송 삭제

```

#### `1` 방송 등록: 새 방송 기록을 추가합니다

질문에 차례대로 답합니다.
```
방송 제목: 롤 랭크 다이아 가자 3일차
카테고리:
  1. 리그 오브 레전드
  2. 저스트 채팅
  3. 발로란트

  8. 기타
번호 선택> 1
방송 날짜 (yyyy-MM-dd, 엔터=2026-11-13):          ← Enter = 오늘
방송 시간(분): 240
최고 시청자 수: 1500
[등록 완료] [ 20] 2026-11-13 | 리그 오브 레전드 | 롤 랭크 다이아 가자 3일차 | 4시간 | 최고 1,500명
```

새 방송에는 ID가 자동으로 붙습니다 (위 예에서는 `20`).

```

  1. 최신순
  2. 오래된순

------------------------------------------------------------
[방송 목록 (최고 시청자 많은순)]
  [  9] 2026-10-23 | 리그 오브 레전드  | 롤 내전 시청자 참여 | 4시간 30분 | 최고 2,104명
  [ 16] 2026-11-08 | 메이플스토리     | 메이플 보스 첫 트라이 | 4시간 40분 | 최고 1,890명
  [  5] 2026-10-12 | 메이플스토리     | 메이플 하이퍼버닝 1일차 | 6시간 | 최고 1,720명

```
읽는 법: `[ID] 날짜 | 카테고리 | 제목 | 방송 시간 | 최고 시청자 수`

#### `3` 방송 검색: 제목이나 카테고리로 찾습니다

```
검색 방법:
  1. 제목 키워드로 검색
  2. 카테고리로 검색
번호 선택> 1
검색할 키워드: 롤
------------------------------------------------------------
[검색 결과 5건]
  [ 17] 2026-11-10 | 리그 오브 레전드  | 롤 랭크 다이아 가자 2일차 | 5시간 | 최고 1,610명
  [ 12] 2026-11-01 | 리그 오브 레전드  | 롤 랭크 다이아 가자 | 4시간 10분 | 최고 1,532명
  ...
```
- `1` 제목 검색: 제목에 키워드가 **포함**된 방송을 찾습니다. 영어는 대소문자를 구분하지 않습니다.
- `2` 카테고리 검색: 카테고리 번호를 고르면 그 카테고리의 방송만 나옵니다.

#### `4` 방송 상세 보기: 방송 하나의 정보와 들어온 후원을 봅니다

최근 방송 5개가 먼저 보이고, ID를 입력합니다.

```
------------------------------------------------------------
[이 방송의 후원 내역]
  [ 16] 2026-10-23 20:30 | 방송#9 | 일반 후원 | 고양이팬님 10,000치즈 | "내전 최고"
  [ 17] 2026-10-23 21:45 | 방송#9 | 일반 후원 | 치즈부자님 50,000치즈 | "역대 최고 시청자 축하!"

```

#### `5` 방송 수정: 등록한 방송의 내용을 고칩니다

ID를 입력하면 항목마다 현재 값을 보여 줍니다. **바꿀 항목만 새로 입력하고, 나머지는 Enter**를 누르면 그대로 유지됩니다.
```
수정할 방송 ID: 20
현재: [ 20] 2026-11-13 | 리그 오브 레전드 | 롤 랭크 다이아 가자 3일차 | 4시간 | 최고 1,500명
방송 제목 [현재: 롤 랭크 다이아 가자 3일차] (엔터=유지):            ← Enter
카테고리: ...
번호 선택 [현재: 리그 오브 레전드] (엔터=유지)>                     ← Enter
방송 날짜 (yyyy-MM-dd, 엔터=2026-11-13):                            ← Enter
방송 시간(분) [현재: 240] (엔터=유지): 300                          ← 이것만 변경
최고 시청자 수 [현재: 1500] (엔터=유지):                            ← Enter
[수정 완료] [ 20] 2026-11-13 | 리그 오브 레전드 | 롤 랭크 다이아 가자 3일차 | 5시간 | 최고 1,500명
```

#### `6` 방송 삭제: 방송 기록을 지웁니다

```
삭제할 방송 ID: 20
삭제 대상: [ 20] 2026-11-13 | 리그 오브 레전드 | 롤 랭크 다이아 가자 3일차 | 5시간 | 최고 1,500명
정말 삭제할까요? (y/n): y
[삭제 완료] 방송 #20 (연결된 후원 0건 함께 삭제)
```
- 그 방송에 들어온 **후원도 함께 삭제**됩니다. 후원이 있으면 삭제 전에 몇 건인지 알려 줍니다.
- `n`을 입력하면 취소됩니다.

### 5-3. `2` 후원(치즈) 관리

```
[후원(치즈) 관리]
  1. 후원 등록
  2. 전체 후원 목록
  3. 방송별 후원 조회
  4. 미션 결과 처리 (성공/실패)
  5. 후원 삭제
  0. 뒤로
```

**후원 종류 3가지**

| 종류 | 추가로 입력하는 것 | 정산 |
|------|--------------------|------|
| 일반 후원 | 메시지 (없으면 Enter) | 항상 전액 |
| 영상 후원 | 영상 주소, 재생 시간(초) | 항상 전액 |
| 미션 후원 | 미션 내용 | **미션 성공 시에만** 전액, 진행중·실패면 0 |

#### `1` 후원 등록: 방송에 들어온 후원을 기록합니다

후원은 **반드시 방송에 연결**됩니다. 최근 방송 5개가 먼저 보입니다.
```
후원이 들어온 방송 ID: 19
후원자 닉네임: 고양이팬
후원 종류:
  1. 일반 후원
  2. 영상 후원
  3. 미션 후원
번호 선택> 3
후원 금액(치즈): 10,000
후원 시각 (HH:mm, 엔터=21:30): 22:00
미션 내용: 3킬 이상 하기
[등록 완료] [ 34] 2026-11-12 22:00 | 방송#19 | 미션 후원 | 고양이팬님 10,000치즈 | 미션 "3킬 이상 하기" [진행중]
```
- 처음 보는 닉네임이면 **시청자 목록에 자동 등록**됩니다.
- **블랙리스트 시청자**의 닉네임을 입력하면 등록이 거부됩니다.
  ```
  후원자 닉네임: 도배맨
    [!] '도배맨' 님은 블랙리스트에 등록된 시청자라 후원을 등록할 수 없습니다.
  ```
- 날짜는 방송 날짜로 자동 지정되고, 시각만 입력합니다.

#### `2` 전체 후원 목록: 모든 후원을 시간순으로 봅니다

```
  [  1] 2026-10-02 20:15 | 방송#1 | 일반 후원 | 고양이팬님 5,000치즈 | "첫 방송 축하해요!"
  [  3] 2026-10-02 22:05 | 방송#1 | 미션 후원 | 고양이팬님 10,000치즈 | 미션 "이번 판 이기기" [성공]
  ...
```
읽는 법: `[후원 ID] 일시 | 방송 ID | 종류 | 후원자, 금액 | 메시지·영상·미션 내용`

#### `3` 방송별 후원 조회: 특정 방송에 들어온 후원만 봅니다

```
방송 ID: 6
['노래방송, 신청곡 받아요' 후원 내역]
  [ 11] 2026-10-14 22:00 | 방송#6 | 일반 후원 | 새벽감성님 5,000치즈 | "신청곡: 밤편지, 아이유"
  [ 12] 2026-10-14 22:30 | 방송#6 | 영상 후원 | 새벽감성님 2,000치즈 | 영상 https://youtu.be/example02 (3분 30초)
```

#### `4` 미션 결과 처리: 진행중인 미션을 성공 또는 실패로 바꿉니다

```
[진행중인 미션]
  [ 32] 2026-11-12 22:00 | 방송#19 | 미션 후원 | 배그고수님 10,000치즈 | 미션 "솔로 치킨 먹기" [진행중]
처리할 후원 ID: 32
결과:
  1. 성공
  2. 실패
번호 선택> 1
[처리 완료] [ 32] ... 미션 "솔로 치킨 먹기" [성공]
```
- **성공**으로 바꾸면 그 금액이 통계의 **정산 금액에 더해집니다**.
- **실패**로 바꾸면 환불로 보고 정산에서 빠집니다.
- 진행중인 미션이 없으면 `진행중인 미션이 없습니다.`가 나옵니다.

#### `5` 후원 삭제: 잘못 입력한 후원을 지웁니다

```
삭제 대상: [ 34] ...
정말 삭제할까요? (y/n): y
[삭제 완료] 후원 #34
```

### 5-6. 처음 써 보는 분을 위한 5분 체험

1. `4` → `1` → `1`: 11월 요약을 보고 **정산 금액**을 기억합니다.
2. `0` → `2` → `4`: 진행중인 미션(`32`)을 **`1` 성공**으로 처리합니다.
3. `0` → `4` → `1` → `1`: 11월 **정산 금액이 10,000치즈 늘어난 것**을 확인합니다.
4. `0` → `3` → `5`: `롤알못`을 블랙리스트에 추가합니다 (`y`).
5. `0` → `2` → `1`: 아무 방송 ID를 입력하고 닉네임 `롤알못` → **등록이 거부**됩니다.
6. `0` → `0`: 저장하고 종료한 뒤 **다시 실행**해서 3~5번의 변경이 그대로 남아 있는지 확인합니다.

## 6. 프로그램 구조

```
chzzk-manager/
├── src/
│   ├── app/        Main                프로그램 시작점, 객체 생성·연결
│   ├── model/      Broadcast           방송 기록
│   │               Viewer              시청자
│   │               Donation (추상)     후원 공통 정보 + 정산 규칙
│   │                ├ ChatDonation     일반 후원 (메시지)
│   │                ├ VideoDonation    영상 후원 (영상 주소, 길이)
│   │                └ MissionDonation  미션 후원 (미션 내용, 상태) - 정산 규칙 재정의
│   │               Category, DonationType, MissionStatus (enum)
│   ├── service/    BroadcastService    방송 CRUD·검색·정렬       (ArrayList)
│   │               DonationService     후원 등록·조회·미션 처리   (ArrayList)
│   │               ViewerService       시청자·블랙리스트          (HashMap)
│   │               StatisticsService   통계 계산                  (EnumMap, HashMap, TreeSet)
│   ├── storage/    CsvSerializable     CSV로 저장 가능한 객체 (인터페이스)
│   │               CsvFileStore<T>     CSV 파일 1개 읽기/쓰기 (제네릭)
│   │               DataStore           CSV 3개 일괄 저장/불러오기
│   │               CsvUtil, LoadResult<T>
│   ├── ui/         ConsoleUI           메뉴 화면
│   │               InputReader         입력 검증 (잘못 입력하면 다시 물어봄)
│   └── exception/  DataNotFoundException, BlacklistedViewerException,
│                   CsvFormatException, InputEndedException
├── test/selftest/  SelfTest            자동 테스트 17개
├── data/           broadcasts.csv, donations.csv, viewers.csv (샘플 데이터)
├── run.bat / run.sh       실행 스크립트
└── test.bat / test.sh     테스트 스크립트
```

**계층 구조:** `ui` → `service` → `model`, 파일 입출력은 `storage`가 전담합니다. 화면 코드와 데이터 처리 코드를 분리해서, 나중에 Swing 화면으로 바꿔도 `service`와 `model`은 그대로 쓸 수 있습니다.

### 객체지향 설계 포인트

| 개념 | 적용 위치 |
|------|-----------|
| 캡슐화 | 모든 필드는 `private`. setter에서 값 검증 (예: 방송 시간 1~1440분, 금액 1 이상) |
| 상속 | `Donation` ← `ChatDonation`, `VideoDonation`, `MissionDonation` |
| 추상 클래스 / 다형성 | `getType()`, `describeDetail()`을 하위 클래스가 구현. `getSettledAmount()`는 `MissionDonation`만 재정의해서 통계 코드가 후원 종류를 신경 쓰지 않음 |
| 인터페이스 | `CsvSerializable`, `CsvFileStore.CsvParser<T>` (함수형 인터페이스, 메소드 참조 `Broadcast::fromCsv`로 전달) |
| 제네릭 | `CsvFileStore<T extends CsvSerializable>`, `LoadResult<T>`, `InputReader.choose<T>(...)` |
| 팩토리 메소드 | `Donation.fromCsv()`가 CSV의 type 값을 보고 알맞은 하위 클래스 객체를 생성 |
| Comparable / Comparator | 방송·후원의 기본 정렬, `SortOrder` enum이 정렬 기준을 보유 |

### 컬렉션 사용

| 컬렉션 | 용도 |
|--------|------|
| `ArrayList` | 방송 목록, 후원 목록 |
| `HashMap<String, Viewer>` | 닉네임으로 시청자를 바로 조회 |
| `HashSet<Integer>` | 파일을 불러올 때 중복 ID 검사 |
| `EnumMap` | 카테고리별·후원 종류별 통계 |
| `TreeSet<YearMonth>` | 데이터가 있는 달 목록 (최근 달부터 정렬) |

## 8. 예외 처리

| 상황 | 처리 |
|------|------|
| 메뉴나 숫자 입력에 문자를 입력 / 범위를 벗어난 숫자 | "숫자를 입력해 주세요" 등을 안내하고 다시 입력받음 |
| 날짜·시각 형식 오류 (예: `2026-13-01`, `25:99`) | 형식 예시를 보여주고 다시 입력받음 |
| 존재하지 않는 방송·후원 ID, 닉네임 | `DataNotFoundException` → 안내 메시지 후 메뉴로 복귀 |
| 블랙리스트 시청자의 후원 | `BlacklistedViewerException` → 등록 거부 |
| 미션이 아닌 후원의 미션 결과 처리, 중복 닉네임 등록 | `IllegalArgumentException` → 안내 메시지 |
| 데이터 파일이 없음 | 빈 파일을 새로 만들고 빈 상태로 시작 |
| CSV 줄 형식 오류 (필드 개수, 숫자, 날짜, enum 값, 따옴표) | 해당 줄만 건너뛰고 "n번째 줄을 건너뜀: 이유" 경고 출력 |
| 후원이 존재하지 않는 방송을 가리킴 / 중복 ID | 해당 항목만 건너뛰고 경고 출력 |
| 파일 저장 실패 (권한 등) | 오류를 안내하고 프로그램은 계속 실행 (데이터는 메모리에 유지) |
| 저장 도중 중단 | 임시 파일(`.tmp`)에 먼저 쓰고 교체하므로 기존 파일이 깨지지 않음 |
| 입력 스트림 종료 (Ctrl+Z / Ctrl+D) | 데이터를 저장하고 안전하게 종료 |
